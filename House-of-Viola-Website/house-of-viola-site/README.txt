HOUSE OF VIOLA — OFFLINE SITE SNAPSHOT

Open site/index.html in a browser to view the captured storefront. Other captured category, product, account, cart and tracking pages are in the same folder. Images, CSS and JavaScript assets downloaded from the public site are included where available.

IMPORTANT LIMITATIONS
This ZIP is a static snapshot of publicly accessible pages, not the original website project or source code. The server did not expose its PHP source, database, server configuration, or backend services, so those are not included. Forms, account sign-in, cart updates, order tracking, WhatsApp order actions and checkout will not operate as a live store when opened offline. Some links may still require the internet.
